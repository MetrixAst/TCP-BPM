## Полное описание (до 4000 знаков)

```
Metrix BPM — корпоративное приложение для сотрудников. Через него можно войти в систему, отмечать приход и уход по QR, проходить назначенные обходы с чек-листами и фото, а также работать с заявками.

Возможности

• Статус дня — отметки прихода и ухода по QR-коду, история за текущий день.
• Обходы на сегодня — список назначенных обходов с окнами по времени и прогрессом по точкам.
• Маршрут обхода — точки с адресами, отметка прохождения по QR, фото и комментарий к чек-листу.
• Мои задачи — поручения со сроками, приоритетом и статусом.
• Заявки — создание заявки с категорией, приоритетом, описанием и помещением.
• Работа без сети — отметки и заявки сохраняются на устройстве и уходят на сервер, когда связь появится.

Для кого

Приложение рассчитано на сотрудников эксплуатации, службы безопасности и технических служб на объектах, которые обслуживаются системой Metrix BPM.

Доступ

Вход выполняется по учётной записи, которую выдаёт администратор системы организации. Самостоятельная регистрация не предусмотрена. Приложение работает только с сервером той организации, к которой относится учётная запись.
```

## Доступ к приложению (App access)

Вся функциональность требует входа. Указать учётные данные для проверки:

```
Логин: appreview
Пароль: Review!2026Mx
```

Демо-данные этого аккаунта переносятся на текущую дату задачей celery-beat
`mobile-refresh-review-demo`, поэтому проверяющий не увидит пустые экраны.

## Данные и безопасность (Data safety)

Общее: данные передаются по HTTPS, шифрование при передаче — да. Данные не
продаются и не используются для рекламы или трекинга. Удаление данных —
через администратора системы, путь описан на странице политики.

| Тип данных | Собирается | Передаётся | Цель | Обязательно |
| --- | --- | --- | --- | --- |
| Имя | Да | Да | Работа приложения, управление аккаунтом | Да |
| Адрес электронной почты | Да | Да | Работа приложения, управление аккаунтом | Да |
| Идентификаторы пользователей | Да | Да | Работа приложения, управление аккаунтом | Да |
| Точное местоположение | Да | Да | Работа приложения | Да |
| Фото | Да | Да | Работа приложения | Нет |
| Идентификаторы устройства | Да | Да | Работа приложения (push-уведомления) | Нет |

Местоположение запрашивается только в момент чек-ина и отметки точки обхода,
фото — только когда сотрудник сам прикладывает снимок.
